# Better Vanilla

Better Vanilla is a Fabric mod for Minecraft 26.3 that enhances Vanilla Minecraft and improves the progression while maintaining the vanilla feel. It features a deepened underground, improved progression system, and much more.

## Key Features

- Expanded underground down to Y -192, with own layers for each progression ore.
- Golden armour and tools buffed to sit between iron and diamond tier.
- Rebalanced food items, with new max stack sizes, nutrition, and saturation values.
- Chainmail armour is craftable, requiring iron chain as the ingredient.
